# Morfo Fotos

Herramienta web para fotografiar morfoespecies por proyecto, renombrar las fotos (CODIGO_1, CODIGO_2…) y descargar un ZIP con carpetas numeradas ("1. CODIGO") y el Excel de muestras. Funciona sin internet y se puede instalar en el celular.

Enlace: https://rubianoperezsergiodaniel-collab.github.io/morfo-fotos/

## Homologador de Morfos

Compara las fotos de un proyecto (carpetas `1. CODIGO/…`) contra fotos y un PDF de referencia, sugiere la especie más parecida con IA (DINOv2 o CLIP, en el navegador) y escribe la especie homologada en una copia del Excel del proyecto, con una hoja de trazabilidad por foto. Las muestras sin coincidencia quedan como PENDIENTE.

Enlace: https://rubianoperezsergiodaniel-collab.github.io/morfo-fotos/homologar.html
